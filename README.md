### 2. **sunil_salvi_cv_interactive.html**

---

### Interactive HTML Version (sunil_salvi_cv_interactive.html)

#### Option A: Self-Host on Free Platforms

**Option 1: GitHub Pages (Recommended - Free Forever)**

1. Create a GitHub account at https://github.com
2. Create a new repository named `portfolio` or `cv`
3. Upload `sunil_salvi_cv_interactive.html` to the repository
4. Go to Settings → Pages
5. Select "Deploy from a branch"
6. Select main branch and root folder
7. Your CV will be live at: `https://yourusername.github.io/cv`

**Share this link in:**
- Email signature
- LinkedIn profile (add link to "Personal Website")
- Your email closing signature
- Business cards (QR code to URL)

---

**Option 2: Netlify (Free - Alternative)**

1. Visit https://netlify.com
2. Sign up (can use GitHub account)
3. Drag and drop `sunil_salvi_cv_interactive.html` to deploy
4. Your CV will be instantly live with a custom domain

---

**Option 3: Local File (No hosting needed)**

Simply open `sunil_salvi_cv_interactive.html` in any web browser:
- Double-click the file on your computer
- Right-click → "Open with" → Choose your browser
- Perfect for sharing via email or USB drive

---

#### Option B: Embed on Your Website

If you have your own website, add this code to embed the CV:

```html
<iframe src="path/to/sunil_salvi_cv_interactive.html" 
        width="100%" 
        height="800px" 
        frameborder="0">
</iframe>
```
